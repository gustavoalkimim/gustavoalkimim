**It's your move — you play White.** Pick a move below: each one reads **from → to** (`e2→e4` moves the piece on e2 to e4, `×` is a capture). Columns are **a–h** left to right, rows **1–8** from the bottom.

<details>
<summary><b>❓ How to play (step by step)</b></summary>

1. **Pick a move** in the table below and click it. `e2→e4` moves the piece on **e2** to **e4**.
2. GitHub opens a **New issue** page with everything already filled in. Don't change anything — just click **Create**. (You need to be logged in to GitHub.)
3. **Wait about a minute.** A GitHub Action checks your move, my engine thinks for ~3 seconds and plays Black.
4. The bot **replies on your issue** with the engine's move and closes it. Refresh this page to see the new position — the board image can take a few minutes to update because GitHub caches it.

Everyone plays the same game together. If two people move at the same time, the first issue wins and the second one is told the position changed. Hover a move to see it in chess notation.

</details>

## 🐦 Flappy Bird Swarm, Evolving in Public

[![engine tests](https://img.shields.io/github/actions/workflow/status/gustavoalkimim/gustavoalkimim/flappy-engine-ci.yml?branch=main&label=engine%20tests&style=flat-square&labelColor=302b63)](https://github.com/gustavoalkimim/gustavoalkimim/actions/workflows/flappy-engine-ci.yml) [![weekly training](https://img.shields.io/github/actions/workflow/status/gustavoalkimim/gustavoalkimim/flappy.yml?branch=main&label=weekly%20training&style=flat-square&labelColor=302b63)](https://github.com/gustavoalkimim/gustavoalkimim/actions/workflows/flappy.yml)

> 100 birds, one neural network each, all flying the same pipes at once — written from scratch in C and evolved by a genetic algorithm. The pipes get harder the farther they go, and the swarm trains 2 more generations every Monday. The gold bird is the reigning champion.
